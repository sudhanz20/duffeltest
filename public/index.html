  1. Duffel cannot reach localhost. Start a tunnel in a second terminal:
    npx cloudflared tunnel --url http://localhost:3000
  2. Paste the public https:// URL below and register. Nomad adds /webhook and subscribes to all flight events.
  3. Click Ping. A ping.triggered event appears in the live feed, marked verified.

This site has a public URL, so Duffel can reach it directly. The URL is already filled in.

On Vercel the server cannot save the secret to .env. Copy secret from the live feed into the DUFFEL_WEBHOOK_SECRET setting and redeploy.
