Receive webhooks

  1. Duffel cannot reach localhost. Start a tunnel in a second terminal:
    npx cloudflared tunnel --url http://localhost:3000
    or ngrok http 3000
  2. Paste the public https://… URL it prints below and click Register. The server adds /webhook, subscribes to all events, and saves the secret into .env.
  3. Click Ping. A ping.triggered event should appear in the live feed with a green "verified" badge.

Tunnel URLs change on each restart of a free tunnel. Register again when it changes, and delete the old webhook.
